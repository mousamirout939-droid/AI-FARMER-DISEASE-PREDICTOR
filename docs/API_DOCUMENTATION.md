# API Documentation

Interactive, always-up-to-date docs are auto-generated and served live:

- **Backend (Node/Express)**: `http://localhost:5000/api-docs` (Swagger UI, from `swagger-jsdoc`)
- **AI service (FastAPI)**: `http://localhost:8000/docs` (Swagger UI, auto-generated by FastAPI)
  and `http://localhost:8000/redoc` (ReDoc)

A ready-to-import Postman collection covering both services is at
`postman/AI-Farmer.postman_collection.json`.

## Backend REST API — `http://localhost:5000/api/v1`

All authenticated routes expect `Authorization: Bearer <accessToken>` (obtained from
`/auth/login` or `/auth/register`).

| Method | Route | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | — | Create a farmer/expert account |
| POST | `/auth/login` | — | Email + password login |
| POST | `/auth/google` | — | Google OAuth login (frontend verifies token, sends profile) |
| POST | `/auth/otp/request` | — | Send a 6-digit OTP to email |
| POST | `/auth/otp/verify` | — | Verify OTP and log in |
| POST | `/auth/forgot-password` | — | Send password reset link |
| POST | `/auth/reset-password` | — | Reset password with token |
| POST | `/auth/refresh-token` | — | Exchange refresh token for new access token |
| POST | `/auth/logout` | ✅ | Invalidate refresh token |
| GET | `/auth/me` | ✅ | Current user profile |
| POST | `/predictions` | ✅ | Upload image → AI diagnosis (multipart `image` field) |
| GET | `/predictions` | ✅ | Paginated prediction history |
| GET | `/predictions/:id` | ✅ | Single prediction detail |
| GET | `/predictions/:id/report` | ✅ | Download PDF report |
| DELETE | `/predictions/:id` | ✅ | Delete a prediction |
| GET | `/diseases` | — | List/search disease library |
| GET | `/diseases/:id` | — | Disease detail |
| POST/PUT/DELETE | `/diseases` | ✅ (admin/expert) | Manage disease library |
| GET | `/medicines` | — | List medicines/fertilizers |
| POST/PUT/DELETE | `/medicines` | ✅ (admin/expert) | Manage medicines |
| GET | `/weather` | ✅ | Weather + disease-risk for a location |
| GET | `/market/prices` | ✅ | Mandi prices |
| GET | `/market/schemes` | ✅ | Government scheme info |
| POST | `/chatbot` | ✅ | AI chat (Gemini if configured, rule-based fallback otherwise) |
| GET/POST | `/community` | ✅ | Community feed |
| POST | `/community/:id/like` | ✅ | Toggle like |
| POST | `/community/:id/comments` | ✅ | Comment on a post |
| POST | `/appointments` | ✅ (farmer) | Book an expert appointment |
| GET | `/appointments` | ✅ | List your appointments |
| PATCH | `/appointments/:id/status` | ✅ (expert/admin) | Update appointment status |
| GET | `/notifications` | ✅ | List notifications |
| PATCH | `/notifications/:id/read` | ✅ | Mark as read |
| POST | `/support` | ✅ | Open a support ticket |
| GET | `/support/my` | ✅ | Your tickets |
| GET | `/support` | ✅ (admin) | All tickets |
| POST | `/support/:id/respond` | ✅ (admin/expert) | Respond to a ticket |
| GET | `/admin/stats` | ✅ (admin) | Dashboard analytics |
| GET | `/admin/users` | ✅ (admin) | List/search users |
| PATCH | `/admin/users/:id/status` | ✅ (admin) | Activate/deactivate a user |
| PATCH | `/admin/users/:id/verify-expert` | ✅ (admin) | Verify an expert account |

Every response follows the shape:

```json
{ "success": true, "message": "...", "data": { }, "meta": { "page": 1, "limit": 20, "total": 42 } }
```

## AI Service API — `http://localhost:8000/api/v1`

| Method | Route | Description |
|---|---|---|
| GET | `/health` | Service status, model status, device |
| GET | `/classes` | Supported disease classes + full crop list |
| POST | `/predict` | Upload an image (`file` field), get a full diagnosis |

`POST /predict` response shape:

```json
{
  "predicted_class": "tomato_early_blight",
  "crop": "Tomato",
  "confidence": 0.874,
  "severity_score": 62,
  "all_probabilities": [{ "label": "tomato_early_blight", "probability": 0.874 }],
  "bounding_boxes": [{ "x": 40, "y": 25, "width": 120, "height": 90, "label": "affected_region", "confidence": 0.0 }],
  "heatmap_url": "data:image/jpeg;base64,...",
  "image_quality": { "sharpness_score": 210.5, "brightness_score": 128.4, "is_acceptable": true, "suggestions": [] },
  "model_status": "trained | untrained_demo_mode"
}
```

`model_status` is always present so callers never mistake demo output (untrained network) for
a real diagnosis.
